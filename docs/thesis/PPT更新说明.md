# 答辩PPT更新说明

更新时间：2026-03-13  
更新文件：`答辩PPT.pptx`

## 本轮调整目标

本次更新不再沿用“单次实验 + 六模式排行榜”的旧口径，而是与论文最新的 90 组重复实验结果保持一致，采用：

- 渐进叠加主线：`D / A / B / C`
- 组件消融补强：`C / E / F`
- 六模式总览辅助：仅用于展示整体分布，不承担核心归因

## 主要变化

### 1. 实验设计页重写

- “四方案渐进消融”改为“渐进叠加 + 组件消融”
- 明确写出实验规模：`6模式 × 3问题 × 5次重复 = 90组实验`
- 主实验与消融实验分开叙述，不再混成一条排行榜逻辑

### 2. 实验结果区重排

实验部分现按以下顺序展示：

1. 六模式总览页  
   作用是展示全局分布，强调 `C_iterative` 平均总分最高（23.87 ± 1.77）
2. 四方案主实验页  
   重点结论为：
   - `C_iterative` 稳定最优
   - `B_data_aware` 稳定优于 `A_template / D_baseline0`
   - `A_template` 与 `D_baseline0` 差距有限，不再宣称 `A < D`
3. 组件消融页  
   重点结论为：
   - 移除数据感知或知识图谱都会拉低平均表现
   - 知识图谱收益具有任务依赖性，不能再写成“移除图谱总体更好”

## 旧口径已删除

本次更新删除或停止使用以下旧说法：

- `A < D < B < C` 是稳定梯度
- “知识图谱约束悖论”作为主发现
- `F > C`、“移除知识图谱后总体更好”
- “当前还没做重复实验，后续建议 n≥5”

## 当前答辩主线

建议答辩时按下面的顺序讲：

1. 六模式总览先给全局印象
2. 回到四方案主实验解释系统为什么逐步变好
3. 再用消融结果解释数据感知和知识图谱各自贡献
4. 最后用应用案例说明系统如何端到端落地

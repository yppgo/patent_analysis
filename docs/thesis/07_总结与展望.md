# 第七章 总结与展望

## 7.1 研究结论

本文围绕"数据感知的多智能体专利分析方案自动生成"开展研究，完成了问题定义、系统设计、工程实现与实验验证四项工作。

在问题层面，本文明确指出现有 LLM 自动化分析系统的核心短板在于规划阶段弱证据：系统能够执行代码，但未必能够在给定数据条件下设计高质量方案。该问题在专利计量场景中尤其突出，因为任务不仅要求结果产出，更要求变量解释与方法匹配。

在方法层面，本文提出"数据感知前置 + 双知识图谱协同 + 两轮迭代优化"的整体框架：先进行数据证据提取，再进行方案规划；先确定机制路径，再确定方法实现；先完成探索分析，再执行验证分析。

在工程层面，本文实现了基于 LangGraph 的四智能体系统，并完成从输入问题到输出报告的端到端闭环，形成可复跑、可追踪、可审计的实验资产。

在实证层面，本文通过四方案渐进消融验证了关键机制贡献，得到清晰性能梯度 A < D < B < C，为方法有效性提供了直接证据。结合实验结果，形成以下四项具体结论：

第一，数据感知是提升方案质量的关键条件。引入 DataPreview、GraphPreview 与洞察生成后，系统在针对性引用数、综合评分等指标上均显著改善，说明基于数据证据的规划可系统性提升方案质量。

第二，知识图谱不是无条件增益。实验发现 A_template 低于 D_baseline0，表明知识约束若脱离数据证据，可能引发模板化和过约束问题。该结论扩展了现有 KG+LLM 研究中"加图谱即增益"的默认假设。

第三，两轮迭代有效提升分析深度与创新性。C_iterative 在方法多样性、参数丰富度、深度评分等维度领先，说明反馈驱动机制能将一次性分析升级为层级化分析。

第四，系统工程可用性达到应用级门槛。四方案执行成功率均为 100%，表明在当前任务范围内，系统具备稳定执行和可靠输出能力。

在研究贡献方面，理论上，本文把自动化分析研究的关注点从"执行正确性"前移到"规划合理性"，并提出了"知识约束悖论"这一具有可检验性的研究命题。方法上，本文给出可复用的系统范式：数据感知组件负责证据抽取，双图谱组件负责结构约束，迭代机制负责深度提升，三者组合可迁移到其他结构化分析场景。实践上，本文形成了可落地工程资产，包括主流程代码、实验输出和评估脚本，可直接支持后续复验与扩展开发。

## 7.2 研究展望

本文仍存在以下局限，每项局限均对应实验中的具体观测：

第一，问题规模与统计稳健性有限。当前实验仅覆盖三个研究问题且每组仅运行一次。尽管三个问题均独立呈现 A < D < B < C 的一致梯度，降低了偶然性风险，但缺少多次重复运行和置信区间估计，统计外推边界仍受限。

第二，评估主体单一。LLM-as-Judge 虽采用匿名并列评分和低温度参数（temperature=0.1）缓解偏好偏差，但仍可能存在系统性评分偏移。当前评估未引入人工专家盲审做交叉验证。

第三，数据感知的"聚焦效应"尚需优化。实验发现 B_data_aware 在针对性引用数和语义评分上领先 D_baseline0，但在列覆盖率和任务数等结构指标上反而下降，反映数据洞察驱动的规划倾向于"以广度换深度"。该聚焦策略在当前三个问题中表现积极，但在需要更广泛探索的开放性问题中是否仍然适用尚未验证。

第四，知识约束的适配条件不够清晰。实验发现的"知识图谱约束悖论"（A < D）表明知识约束并非无条件增益，但当前仅验证了"约束失效"的存在性，未系统探索约束强度与数据证据强度的最优匹配关系。

第五，跨域验证不足。当前数据集集中于数据安全专利，尚未在其他技术领域做系统迁移验证。

围绕上述局限，后续研究可从五个方向推进：

（1）增强实验统计稳健性。对每组实验进行多次独立运行（n≥5），计算 bootstrap 置信区间，并引入 Friedman 检验或 Wilcoxon 符号秩检验比较各模式间的差异显著性。同时扩展研究问题规模至 10 个以上，覆盖更多分析类型（如专利组合分析、技术生命周期预测），构建标准化评估基准。

（2）构建混合评审框架。将 LLM-as-Judge 与领域专家盲审结合，形成"自动评估 + 专家复核"的双层机制。引入评分者间一致性指标（如 Krippendorff's α）量化评估质量，并分析 LLM 评分与人工评分的系统性偏差模式。

（3）引入自适应约束强度机制。针对知识约束悖论，研究基于数据证据强度动态调节约束权重的方法：当数据洞察信号强（如显著相关系数多、图结构特征丰富）时降低图谱约束权重，让数据驱动主导；当数据信号弱时提升图谱约束权重，提供结构化引导。该机制可通过 Prompt 中的约束层次控制或注意力加权实现。

（4）优化数据感知的广度-深度平衡。针对 B 模式的聚焦效应，研究动态任务数量校准策略：在保持高针对性的同时，通过最低覆盖率阈值约束确保方案不遗漏关键数据维度。具体可在蓝图生成阶段增加"列覆盖检查"环节，当已规划任务的列覆盖率低于预设阈值时，自动补充探索性任务。

（5）推进跨领域迁移验证。选择生物医药（结构化程度高、领域知识密集）、新能源（时间趋势明显）和半导体（多国竞争激烈）三个领域的专利数据集进行系统迁移测试，验证数据感知机制和双图谱框架的领域适应性，并识别需要定制化扩展的组件。

总体而言，本文验证了数据感知多智能体专利分析框架的有效性，并通过实验揭示了若干值得深入研究的现象（知识约束悖论、数据感知聚焦效应）。这些发现不仅为当前系统的优化提供了方向，也为后续面向更大规模、更复杂场景的自动化科学分析系统奠定了方法与工程基础。

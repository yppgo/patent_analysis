# 附录符号说明

## A.1 变量与符号

- `N`：样本总数。
- `Y`：被解释变量（如标准化被引量）。
- `X`：解释变量向量（如技术多样性、网络特征等）。
- `C`：控制变量向量（如专利年龄、法律状态、年份固定效应）。
- `β`：回归系数向量。
- `ε`：随机误差项。
- `p`：显著性概率值。
- `R²`：拟合优度统计量。

## A.2 缩略语

- `LLM`：Large Language Model，大语言模型。
- `KG`：Knowledge Graph，知识图谱。
- `DAG`：Directed Acyclic Graph，有向无环图。
- `IPC`：International Patent Classification，国际专利分类。
- `CBR`：Case-Based Reasoning，案例推理。
- `RAG`：Retrieval-Augmented Generation，检索增强生成。
- `NLP`：Natural Language Processing，自然语言处理。
- `OLS`：Ordinary Least Squares，普通最小二乘法。
- `BERT`：Bidirectional Encoder Representations from Transformers，双向编码器表示。
- `SOP`：Standard Operating Procedure，标准作业程序。
- `API`：Application Programming Interface，应用程序编程接口。
- `JSON`：JavaScript Object Notation，一种轻量级数据交换格式。

## A.3 模式命名

- `D_baseline0`：纯 LLM 基线模式。
- `A_template`：知识图谱模板模式。
- `B_data_aware`：数据感知单轮模式。
- `C_iterative`：数据感知双轮迭代模式。

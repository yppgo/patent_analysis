## 建议的写作顺序

按"素材最充分 → 最需要思考"的顺序写，保持写作动力：

```
第五章（实验评估）    ← 素材最齐，直接整理，最快出成果
     ↓
第二章（研究综述）    ← 素材较齐，扩写调研内容
     ↓
第四章（原型实现）    ← 对着代码写，工作量大但不需太多创造性
     ↓
第三章（系统设计）    ← 需要抽象和提炼，架构图是重点
     ↓
第六章（应用示例）    ← 从实验输出提取案例
     ↓
第一章（绪论）        ← 等全文写完再回头写，更有全局视角
     ↓
第七章（总结展望）    ← 最后写
     ↓
摘要                  ← 最后的最后
```

## 协作方式

我可以协助的工作：
1. **起草文字**：根据现有素材和代码，为每个小节生成论文初稿
2. **提炼代码**：从源码中提取关键算法，写成伪代码或流程描述
3. **制作表格**：整理实验数据为论文格式的表格
4. **画图建议**：描述每张图应包含的内容和布局（实际绑图需你用 Visio/draw.io）
5. **润色修改**：对你写好的段落进行学术语言润色

建议的工作模式：**按章节推进，每次完成一个小节后给我看，我来修改和补充。**
